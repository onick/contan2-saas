Leídos los `.tsx` y `.module.css` de date-range-picker, calendar (cabecera), popover, tooltip, otp-input, number-field, split-button y dropdown-menu, más `lib/use-today.ts`, `lib/motion-tokens.ts` → `registry/motion-tokens.ts`, `registry/foundation.css` y el README (Theming).

### Hallazgo clave de dependencias
- **`date-range-picker` NO depende de `calendar` ni de `popover`.** Es autocontenido (grilla de mes propia y superficie que crece del trigger al panel). ### API por componente (Arc)

**DateRangePicker.** Props: `value?/defaultValue?: {start: Date; end: Date} | null`, `onChange(range)`, `label`, `placeholder`, `presets: {label; range(today)}[]`, `minDate`, `maxDate`, `weekStartsOn: 0|1` (default 0), `locale` ("en-US"), `months: 'auto'|1|2` (dos meses si caben 712 px), `boundary()`, `className`. Flujo: un clic fija el ancla, el segundo cierra el rango, "Apply" confirma; "Cancel"/Escape cierran y devuelven el foco al trigger. A11y: trigger `aria-haspopup="dialog"`, `aria-expanded`, `aria-label="label: valor"`, `disabled` hasta hidratar; panel `role="dialog"`; cada mes `role="grid"` con `columnheader` y `gridcell aria-selected`; días como botones con `aria-label` largo y `aria-current="date"`; tabindex itinerante; presets en `role="group"` con `aria-pressed`; región `aria-live`. Teclado: flechas, Home/End, PageUp/PageDown (Shift = año), flechas en presets, Escape. Depende de `motion`: superficie trigger→panel, `layoutId` del valor, rodado de palabras, barras de rango por semana, extremos, deslizado de meses, resaltado del preset, blur. Se porta casi igual: aritmética de días, `segments` por semana, navegación por teclado, `tabbable` y `reveal()`.

**OtpInput.** Props: `length` (6), `value`, `onChange`, `label`, `description`, `error`, `autoFocus`, `disabled`, `inputMode`. N inputs de 1 carácter en `role="group"`, cada uno con `aria-label "label, digit i of N"`, `aria-describedby`, `aria-invalid`; solo el primero `autoComplete="one-time-code"`. Pegado reparte dígitos; flechas; Backspace en vacío borra el anterior; error `role="alert"`. `motion`: glifo que sube, anilla de foco deslizante, shake en error, altura del mensaje.

**NumberField.** Props: `label`, `value/defaultValue`, `onValueChange`, `min`, `max`, `step`, `largeStep`, `description`, `disabled`, `id`, `prefix/suffix`, `scrub`, `locale`, `formatOptions`, `size`, `limitHint`. Input `type="text" role="spinbutton"` con `aria-valuenow/min/max/valuetext`; botones "Increase/Decrease {label}" con **`aria-disabled` en el tope** (enfocables; al presionar, el valor "tensa"). Mantener presionado repite; ↑/↓ (Shift = paso grande), PageUp/PageDown, Home/End, Enter confirma, Escape revierte; scrub en el label; borrador válido se aplica en vivo; en el límite: nota "Max N", anuncio "N, maximum", tinte warning. `motion`: odómetro por dígito, afijos, bump, shake, nota, altura.

**SplitButton.** Props: `label`, `actions: {label; onSelect?; disabled?; destructive?; icon?}[]`, `onClick`, `disabled` (ambas mitades), `icon`, `variant: primary|secondary`. Radix DropdownMenu `align="end"` `loop`; chevrón con `aria-label "label more actions"`. `motion`: morph de ancho/glifos/ícono (**se descarta**). Menú ya CSS puro (`@starting-style`, `--i`, salida 130 ms con keyframe no-op). No soporta `href`: agregarlo para descargas.

**DropdownMenu (movimiento).** Panel crece desde el borde del trigger según `data-side`; ítems escalonados con `--i` (tope 4 × 35 ms); salida 130 ms con `animation: menu-exit` no-op para que Radix espere; resaltado deslizante medido en `onFocus` (`offsetTop/offsetHeight`), tono danger; chevrón 180° con `data-state=open`; reduced motion = solo opacidad.

- **Utilidades en JSX** con `cn()` y variantes de datos (`data-[state=open]:…`, `aria-pressed:…`, `aria-[invalid=true]:…`, `disabled:`).
- **CSS propio solo para:** keyframes, `@starting-style`, selectores compuestos, propiedades inline animadas, máscaras y `@media (prefers-reduced-motion: reduce)`.
- **Dónde vive:** `components/ui/arc/arc.css` (tokens `:root` + `@import "./<pieza>/<pieza>.css" layer(components);` por pieza) y una sola línea en `app/globals.css`: `@import "../components/ui/arc/arc.css";`. Cada bloque edita solo su `<pieza>.css`. Prefijo de clases `arc-<pieza>-*`.

### Bloque A: DateRangePicker → Reportes (+ Puerta/reportes; Registros opcional)

API portada en `components/ui/arc/date-range-picker/DateRangePicker.tsx`:

```ts
type Ymd = string; // 'YYYY-MM-DD', inclusivo
interface YmdRange { from: Ymd; to: Ymd }
interface RangePreset { key: string; label: string; range: (today: Ymd) => YmdRange }
interface DateRangePickerProps {
  value: YmdRange;
  onChange: (r: YmdRange, presetKey: string | null) => void;
  presetKey?: string | null;           // etiqueta del trigger SIN depender de "hoy" (SSR-safe)
  presets?: RangePreset[];
  label?: string;                       // 'Período'
  min?: Ymd; max?: Ymd | 'today';
  maxDays?: number;                     // 366 = MAX_REPORT_RANGE_DAYS
  weekStartsOn?: 0 | 1;                 // default 1 (lunes)
  timeZone?: string;                    // default 'America/Santo_Domingo'
  months?: 'auto' | 1 | 2;
  disabled?: boolean; className?: string;
}
```

## 8. Riesgos

1. Primitivos duplicados: no se portan popover/tooltip; el picker usa nuestro `Popover` (se pierde el morph, aceptado). 2. Fechas: todo con `Intl` + días época; sin librerías. 3. OTP: input único + longitud aprendida (rate limit 8/min). 7. `aria-disabled` y Playwright: PUE-01h se reescribe; KIO-05a se acota; jest-dom no lo reconoce. 8. `ReportesDashboard.tsx` compartido A/D → cola D.3. 9. Split esconde formatos: ajustar `ReportesDashboard.test` y RBAC-U07; CSV con semántica distinta. 10. `asChild` del ítem del kit roto → arreglar en D. 11. `--i` por ref callback: degradación inocua. 12. `@starting-style`/`linear()` degradan bien; el kiosko no depende. 13.
